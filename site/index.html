Sixteen design axes the transferability programme depends on, and how many surveyed benchmarks or systems cover each. Axes nobody covers are exactly what a new microscopy testbed has to supply.

One row per execution, four descriptor groups

Every benchmark card and every execution record carries the same four groups. Changing either the agent or the evidence changes what a benchmark result licenses, so both sides are recorded explicitly and never collapsed into a single score. Full field definitions live in schema/SCHEMA.md; machine-readable definitions in schema/benchmark_card.schema.json and schema/execution_record.schema.json.

Agent

Model, vision, retrieval / memory, planner, tool surface, verifier, guards, multi-agent, deterministic execution.

Task

Instrument, workflow depth, perceptual and reasoning demand, tool composition, quantitative tolerance, closed-loop feedback, safety criticality, the benchmark's own taxonomy.

Sample / environment

Material and form factor, real or simulated, signal quality, novelty level held out, calibration and API state, injected faults.

Benchmark

Target population, task source and sampling, size and repetitions, metric type and granularity, split design, leakage risk, safety and abstention scoring.

Controlled vocabularies

Each vocabulary with its gloss and how many surveyed cards use each value. Ordinal vocabularies are listed low to high and encoded as ranks; nominal ones are one-hot.
